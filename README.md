Projeto desenvolvido como atividade acadêmica utilizando HTML, CSS, JavaScript, PHP e MySQL.

O sistema simula o funcionamento de um salão de beleza, permitindo que clientes realizem cadastro, login e agendem serviços de forma simples e organizada. Os dados são armazenados em um banco de dados MySQL, garantindo o registro de clientes, agendamentos e pagamentos.

Funcionalidades
Cadastro e login de clientes.
Agendamento de serviços.
Armazenamento dos dados em banco de dados MySQL.
Registro de pagamentos.
Consulta de agendamentos.
Interface simples e intuitiva.
Tecnologias utilizadas
HTML5
CSS3
JavaScript
PHP
MySQL
XAMPP (ambiente de desenvolvimento local)

Este projeto teve como objetivo colocar em prática conceitos de desenvolvimento web, integração entre front-end e back-end, manipulação de banco de dados, CRUD, lógica de programação e organização de sistemas web.
